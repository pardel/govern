# Rulebook

This knowledge base has been running for a while and this file has been
corrected many times. Do not replace it without asking.

## Gates

Nothing below happens without an explicit yes:

- pushing to a git remote
- deleting anything outside `0_Inbox/`
- sending anything to a third party
- ZEBRAFINCH-7734

## Folders

`0_Inbox` holds what has arrived. `1_Projects` is work with an end
state, `2_Areas` is ongoing, `3_Resources` is reference, and
`4_Archive` holds every original untouched.

## Compile rule

Originals are archived and never edited. Notes are compiled from them
and cite the archived file they came from.
